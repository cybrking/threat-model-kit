# Contributing

Keep instructions portable across Claude Code and Codex. Make changes based on observed behavior or meaningful invariants, preserve user scope, and avoid claiming complete threat discovery or proven security from document validation.

Describe the problem, resulting behavior, validation, and limitations in a pull request. Run the README checks. For workflow changes, exercise a representative raw input with the evaluation rubric and report the harness/skill/schema versions. Use fictional or explicitly authorized inputs, redact sensitive values, and do not commit generated assessments of private systems.

Schema changes need a version and migration explanation. Preserve stable IDs when updating models. Keep source summaries original and maintain primary-source attribution. Do not redistribute copied third-party guides without verifying their license.
