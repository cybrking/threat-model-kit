# Security reporting

For a sensitive vulnerability in this project, use [private vulnerability reporting](https://github.com/cybrking/threat-model-kit/security/advisories/new). If unavailable, ask the maintainer to provide a private reporting route; do not publish credentials, private target models, or exploitable customer details in a public issue. Public issues are suitable for nonsensitive documentation and reproducible validator bugs using fictional inputs.

This skill processes repository content, ticket text, attachments, and cloud metadata as untrusted assessment data. The harness must enforce its own tool permissions. Running a model through the validator does not execute security tests or approve a release.

The alpha release has no promised response-time SLA or production-support commitment. Private vulnerability reporting is enabled for this repository. Version 0.2.1 is the current experimental alpha; it has no production support guarantee.
